# ДЗ 6. API-витрина

Создайте небольшое приложение, которое получает коллекцию из собственного REST API и добавляет в нее новые записи.

Вы сами выбираете предметную область: мероприятия, книги, маршруты, вакансии, учебные встречи или другую понятную тему. Стартовый проект задает только структуру `frontend/ + backend/` и внешний каркас страницы — модель данных и JavaScript-логику нужно спроектировать самостоятельно.

## С чего начать

1. Сделайте fork репозитория и создайте ветку `homework-6`.
2. Прочитайте полное условие в [docs/HOME_WORK.md](docs/HOME_WORK.md).
3. Выберите тему, название ресурса во множественном числе и минимум четыре содержательных поля.
4. Замените демонстрационный ресурс `items` в `backend/db.json` собственным.
5. Запустите backend и только после его проверки подключайте frontend.

## Запуск

Понадобятся Node.js `22.12` или новее, npm и VS Code с расширением Live Server.

Терминал для API:

```bash
cd backend
npm install
npm run dev
```

Frontend:

1. Откройте `frontend/index.html` в VS Code.
2. Запустите **Open with Live Server**.
3. Держите открытыми DevTools → Console и Network.

## Что должно получиться

- `json-server` отдает выбранный ресурс и сохраняет новые записи в `backend/db.json`;
- frontend загружает коллекцию через `GET` и создает записи через `POST`;
- пользователь видит загрузку, результат, пустой список и ошибку;
- форма проверяет данные и очищается только после успешного ответа;
- проект можно запустить по инструкции из репозитория и объяснить на проверке.

Основная часть приносит до **5 баллов**, дополнительные улучшения — еще до **5 баллов**. Отмечать прогресс галочками, прикладывать скриншоты Network или писать отдельный отчет не нужно.
