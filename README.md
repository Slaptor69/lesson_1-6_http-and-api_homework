# Матчи Роналду

Учебная API-витрина любимых матчей Криштиану Роналду. В начальной коллекции семь матчей с командами, датой, турниром, счётом, количеством голов, заметкой и ссылкой на отчёт.

В форме команда Роналду выбирается из списка, соперник вводится вручную. Выбор «дома» или «в гостях» определяет порядок команд в карточке и счёте.

## Запуск

Нужны Node.js 22.12 или новее, npm и расширение Live Server для VS Code.

В терминале из корня проекта:

```bash
cd backend
npm ci
npm run dev
```

API: `http://localhost:3000/matches`. При открытии этого адреса должен появиться JSON со списком матчей.

Откройте `frontend/index.html` через **Open with Live Server**. Оставьте API работающим в отдельном терминале. Данные хранятся в `backend/db.json` и сохраняются после перезапуска API. `node_modules` в Git не добавляется.

## Возможности

- Загрузка коллекции через `GET`, добавление через форму и `POST`.
- Валидация формы, блокировка повторной отправки, сохранение ввода при ошибке.
- Состояния загрузки, результата, пустого списка и ошибки; повторная загрузка.
- A2: удаление через `DELETE` с подтверждением в карточке.
- A3: редактирование через `PATCH` с возможностью отмены.
- B1: поиск по командам и заметкам с debounce и отменой предыдущего запроса.
- B3: тайм-аут запросов через 10 секунд с возможностью повторить действие.
