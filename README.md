# Матчи Роналду

Учебная API-витрина любимых матчей Криштиану Роналду. Тема и стартовая подборка перенесены из ДЗ №5.

## API

Ресурс `matches` хранится в `backend/db.json`. В подборке семь матчей. Каждая запись содержит `id`, команды (`homeTeam`, `awayTeam`), дату (`date`), турнир (`competition`), счёт (`score`), количество голов Роналду (`goals`), заметку (`note`) и ссылку на источник (`source`). Количество голов хранится числом.

Endpoint: `http://localhost:3000/matches`.

## Запуск

Понадобятся Node.js `22.12` или новее и npm. В терминале:

```bash
cd backend
npm ci
npm run dev
```

Откройте `http://localhost:3000/matches` в браузере — API должен вернуть массив из семи матчей. Для остановки сервера нажмите `Ctrl+C`.

`json-server` сохраняет изменения после запросов в `backend/db.json`. Папка `node_modules` в Git не добавляется.

## Frontend

Страница загружает коллекцию через `GET /matches` и показывает карточки с данными матчей. Есть состояния загрузки, пустой коллекции и ошибки. Кнопка «Обновить» повторно получает актуальные данные с сервера, а после ошибки предлагает повторить загрузку.

Для открытия страницы запустите `frontend/index.html` через VS Code → **Open with Live Server**. Сервер API должен работать в отдельном терминале.

Для проверки измените запись в `backend/db.json` и нажмите «Обновить». Временно пустой массив `matches` должен показать пустое состояние, а остановка API — сообщение об ошибке. После запуска API кнопка повтора восстанавливает коллекцию без перезагрузки страницы.
