# API матчей Роналду

Локальный REST API на `json-server`. Данные находятся в `db.json`, основной ресурс — `matches`.

## Запуск

Из папки `backend/`:

```bash
npm ci
npm run dev
```

При изменении зависимостей используйте `npm install` и сохраняйте обновлённый `package-lock.json` в Git.

## Проверка

Откройте `http://localhost:3000/matches` — ответ содержит семь стартовых матчей из ДЗ №5. Конкретная запись доступна по адресу `http://localhost:3000/matches/portugal-spain-2018`.

У матча есть команды, дата, турнир, счёт, количество голов Роналду, заметка и ссылка на источник. `goals` — число, остальные содержательные поля — строки. Счёт хранится строкой вида `3:3`, дата — в формате `YYYY-MM-DD`.

Новые записи отправляются на `/matches` методом `POST`; `id` для них создаёт сервер. `json-server` записывает изменения в `db.json`, поэтому они сохраняются после перезапуска API.
