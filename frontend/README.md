# Frontend

Страница запускается через VS Code → **Open with Live Server**. Backend должен одновременно работать на `http://localhost:3000`.

Стартовый интерфейс намеренно не содержит готовой логики:

- в `index.html` есть каркас коллекции, статуса и формы;
- единственное поле формы показывает ожидаемую структуру разметки, остальные поля нужно добавить под свою модель;
- в `script.js` нужно самостоятельно реализовать запросы, состояния и вывод;
- `styles.css` можно расширять, сохраняя БЭМ-именование.

Полное условие и критерии находятся в [docs/HOME_WORK.md](../docs/HOME_WORK.md).
