# Frontend

Откройте `index.html` через VS Code → **Open with Live Server**. Одновременно запустите backend по [инструкции](../README.md).

Адрес API задан в константе `API_URL` в `script.js`: `http://localhost:3000/matches`.

Страница показывает карточки матчей, позволяет добавлять, редактировать, удалять и искать записи. Для диагностики используйте DevTools → Console и Network.
