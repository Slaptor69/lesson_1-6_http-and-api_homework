# Frontend

Страница запускается через VS Code → **Open with Live Server**. Backend должен одновременно работать на `http://localhost:3000`.

Интерфейс показывает коллекцию матчей Роналду:

- при открытии страницы выполняется `GET http://localhost:3000/matches`;
- карточки содержат команды, дату, турнир, счёт, голы Роналду, заметку и ссылку на источник;
- загрузка, пустая коллекция и ошибка показываются отдельными состояниями;
- «Обновить» или «Повторить загрузку» выполняет новый запрос;
- пока запрос выполняется, кнопка заблокирована;
- значения API выводятся через `textContent`, ссылки разрешены только с протоколами HTTP и HTTPS.

Endpoint задан константой `API_URL` в `script.js`. Форма добавления будет следующим этапом.

Полное условие и критерии находятся в [docs/HOME_WORK.md](../docs/HOME_WORK.md).
